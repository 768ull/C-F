O pacote dos jogos (games.bundle.zip) não é armazenado no repositório. A tarefa Gradle prepareGameBundle o reconstrói a partir dos 25 segmentos ordenados de bundle_parts/ (00.b64 a 24.b64), confere o SHA-256 e o empacota no APK em cada compilação. O arquivo gerado está ignorado no .gitignore e não deve ser enviado em commits. O patch frutris-exit-fix.css é aplicado durante a extração local, dentro do aplicativo, e não altera o pacote original. O espelho do site Algorithomus (pasta site/) é gerado pelo workflow com tools/mirror_site.py, serve o jogo dentro do aplicativo no modo híbrido, está ignorado no .gitignore e também não deve ser enviado em commits.
