O pacote dos jogos independentes (games.bundle.zip) não é armazenado no repositório. A tarefa Gradle prepareGameBundle o reconstrói a partir dos 25 segmentos ordenados de bundle_parts/ (00.b64 a 24.b64), confere o SHA-256 e o empacota no APK em cada compilação. O arquivo gerado está ignorado no .gitignore e não deve ser enviado em commits.

O patch frutris-exit-fix.css é aplicado durante a extração local, dentro do aplicativo, e não altera o pacote original.

O simulador completo Algorithomus é copiado na compilação para a pasta site/ a partir do conteúdo público do domínio original. tools/mirror_site.py baixa as páginas dos aplicativos, percorre as referências estáticas e o media-manifest.json, incluindo fallbackUrl, e valida todas as páginas essenciais e mídias primárias antes de permitir a compilação. A pasta site/ fica ignorada no Git e não deve ser versionada. O WebView serve esses arquivos locais offline e também online; com internet validada, apenas as chamadas dinâmicas /api/ seguem para o servidor original. Respostas de leitura selecionadas são guardadas no localStorage para consulta offline posterior; operações de progresso e desbloqueio continuam dependentes do servidor.
